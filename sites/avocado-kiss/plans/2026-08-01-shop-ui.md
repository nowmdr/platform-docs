# Curated Shop — UI Implementation Plan (Spec A)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Curated Shop frontend for `avocado.kiss` — three routes (`/shop`, `/shop/[category]`, `/product/[slug]`) with reusable components, running standalone on typed fixtures (no DB).

**Architecture:** Tokens-first CSS Modules (no Tailwind — port the Tailwind mockups 1:1 by value). Data flows through a shared contract (`lib/types.ts` + `lib/shop.ts`) whose bodies read from `lib/shop-fixtures.ts` in this plan; Spec B later swaps the bodies to Supabase without touching the UI. RSC by default; only `ProductGrid` is `'use client'` (Load more button).

**Tech Stack:** Next.js 16 (App Router, RSC, TS), `next/image`, `next/link`, CSS Modules, Vitest + RTL.

**Spec:** `platform-docs/sites/avocado-kiss/specs/2026-08-01-shop-ui-design.md` — read it fully first.
**Reference patterns (read, do not copy blindly):** cozycorner `components/{ProductCard,ProductGrid,ProductDetail,CategoryCard,FiltersBar}.tsx` (architecture) and avocado `components/{RecipeCard,EditorsPicks,MediaPlaceholder,TagLabels}.tsx` + `.module.css` (this repo's idioms).
**Visual source of truth:** `avocado.kiss/mockups/version-2/shop/avocado-shop{,-category,-product}.html` — extract exact spacing/type/aspect values from these (strip base64 with the perl/python snippet the main agent used).

**Working rules:** on branch `main`; do NOT commit or push without explicit user permission (commit locally per task is fine — do NOT push). Verify `npm run build` + `npm run lint` green before declaring done. All prices formatted via `formatPrice`; every card image path is `null` → `MediaPlaceholder`.

## Task 3: Loaders over fixtures (the contract seam)

**Files:** Create `lib/shop.ts`

- [ ] **Step 1:** Implement every signature from spec §2 (Лоадеры) over the fixtures. Follow cozycorner's server/client split: keep `resolveProductImage`, `formatPrice`, `productPath`, and `fetchProductsPage` **client-safe** (no `server-only`) because `ProductGrid` calls them in the browser; other loaders may be plain async. Ignore the `client` arg (fixtures are local). `fetchProductsPage({categorySlug, page, pageSize=SHOP_PAGE_SIZE})` sorts deterministically and returns the page slice. `resolveProductImage` mirrors cozycorner but bucket `avocado-kiss-photos`. `formatPrice` = `Intl.NumberFormat('en-US',{style:'currency',currency:'USD'})`.
- [ ] **Step 2:** `npx tsc --noEmit` clean. Commit `feat(shop): fixtures-backed loaders`.
